INTERNET OF THINGS PROJECT

Internet-Based Remote Control of Home Appliances Using Flask

A secure web-based IoT system for remotely controlling household appliances through Flask, HiveMQ Cloud and an ESP32 controller. The system also receives live device and sensor status from the home.
