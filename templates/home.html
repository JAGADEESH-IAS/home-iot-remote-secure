SYSTEM FEATURES

Simple remote IoT control

Everything needed to monitor your connected home and control appliances remotely.

◉

Remote Control

Control the connected Light, Fan and Geyser through the internet from the Devices page.

◇

MQTT Communication

Commands and device status are exchanged between the Flask application and ESP32 using HiveMQ MQTT.

◷

Activity History

Appliance changes are stored persistently and can be reviewed through the History page.

◌

ESP32 Status

The application checks recent ESP32 status messages to show whether the device is actually online.

ARCHITECTURE

How the system works

01

Browser

Mobile or laptop connects to the Flask web application.

→
02

Flask

The web application authenticates the user and sends the requested command.

→
03

HiveMQ

MQTT securely transports commands between the cloud application and the home network.

→
04

ESP32

ESP32 receives the command and controls the connected relay and appliance.
